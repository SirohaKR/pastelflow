# 🌷 파스텔플로우

노션처럼 쓰는 **나만의 파스텔 노트**입니다. 처음부터 한국어로 만들었고, 시놀로지 NAS 같은 곳에서 도커 컨테이너 하나로 가볍게 돌아가요.

## 지금 할 수 있는 것 (1·2단계)

- **블록 에디터**: 빈 줄에서 `/` 를 누르면 제목, 목록, 체크리스트, 표, 코드, 인용, 이미지, 파일 블록을 넣을 수 있어요. 메뉴도 한국어예요.
- **페이지 트리**: 페이지 안에 하위 페이지를 계속 만들 수 있어요. 사이드바에서 끌어다 놓으면 순서나 위치가 바뀌어요.
  - 다른 페이지 위쪽이나 아래쪽 가장자리에 놓으면 그 앞이나 뒤로 옮겨져요.
  - 가운데에 놓으면 그 페이지 안으로 들어가요.
- **꾸미기**: 페이지마다 이모지 아이콘과 커버를 달 수 있어요. 커버는 파스텔 단색이나 직접 올린 이미지 중에서 고를 수 있어요.
- **파스텔 테마**: 강조색 6가지(라벤더, 민트, 피치, 하늘, 벚꽃, 레몬), 라이트·다크·시스템 모드, 페이지 폭(넓게/보통)을 바꿀 수 있어요. 설정은 서버에 저장돼서 다른 기기에서도 그대로 보여요.
- **기타 기능**
  - 즐겨찾기
  - 빠른 검색 (`Ctrl + K`)
  - 휴지통 (되돌리기, 완전 삭제)
  - 자동 저장
  - 사이드바 접기 (`Ctrl + \`)
  - 모바일 화면 지원
- **잠금**: `APP_PASSWORD` 를 정하면 비밀번호를 넣어야 들어올 수 있어요.

### 데이터베이스 (2단계)

사이드바의 **🗃️ 새 데이터베이스** 를 누르면 노션처럼 항목을 모아 두는 페이지가 생겨요. 페이지 ⋯ 메뉴의 **하위 데이터베이스 추가** 로 다른 페이지 안에도 만들 수 있어요.

- **속성 5가지**: 텍스트, 선택(파스텔 태그), 날짜, 체크박스, 숫자
  - 표 머리글을 누르면 이름 바꾸기, 종류 바꾸기, 정렬, 순서 옮기기, 지우기를 할 수 있어요.
  - 종류를 바꿔도 값은 최대한 살려요. 텍스트를 선택으로 바꾸면 있던 글자가 태그가 돼요.
  - 선택 칸에서 이름을 입력하고 Enter 를 누르면 새 태그가 생겨요. ⋯ 를 누르면 태그 이름과 색을 바꿀 수 있어요.
- **보기 3가지** (마지막으로 본 보기를 기억해요)
  - **표**: 칸을 눌러 바로 고쳐요. 머리글에서 오름차순·내림차순 정렬을 할 수 있어요.
  - **칸반**: 선택 속성으로 칸을 나눠요. 카드를 끌어서 다른 칸으로 옮기거나 순서를 바꿔요. 맨 오른쪽에서 새 칸을 만들어요.
  - **캘린더**: 날짜 속성으로 달력에 놓아요. 항목을 다른 날로 끌어 옮기고, 날짜 칸의 ＋ 로 그날 항목을 만들어요. 날짜 없는 항목은 아래에 모여 있어요.
- **항목 열기**: 항목마다 페이지처럼 열려요. 오른쪽 패널에서 속성을 고치고 본문을 BlockNote 로 써요. ⤢ 로 넓게 볼 수 있어요.
- **항목 찾기**: 제목, 텍스트, 숫자, 선택 값으로 걸러 봐요.
- 지운 항목은 휴지통으로 가고, 거기서 되돌릴 수 있어요.

## NAS에 설치하기 (도커)

1. 저장소를 받아요.

   ```bash
   cd /volume1/docker
   git clone https://github.com/SirohaKR/pastelflow.git
   cd pastelflow
   ```

2. 설정 파일과 데이터 폴더를 준비해요. 시놀로지는 바인드 마운트 폴더를 자동으로 만들어 주지 않아서 직접 만들어야 해요.

   ```bash
   cp .env.example .env
   mkdir -p data
   id                      # uid, gid 확인
   ```

   `.env` 에서 `APP_PASSWORD` 를 정하고, `PUID`, `PGID` 를 위에서 확인한 숫자로 맞춰요.
   컨테이너가 켜질 때 `data` 폴더 주인을 이 번호로 알아서 바꾸기 때문에 `chown` 은 따로 안 해도 돼요.

3. 실행해요.

   ```bash
   sudo docker compose up -d --build
   ```

   `http://NAS주소:5190` 으로 접속하면 돼요. 다른 포트를 쓰려면 `docker-compose.yml` 의 `"5190:5210"` 에서 앞쪽 숫자를 바꾸세요.

### 업데이트

```bash
cd /volume1/docker/pastelflow
git pull
sudo docker compose up -d --build
```

### 백업

모든 내용은 `data` 폴더에 들어 있어요.

- `data/pastelflow.db`: 페이지, 데이터베이스 항목, 설정
- `data/uploads/`: 올린 이미지와 파일

이 폴더만 복사해 두면 돼요.

### 외부에서 접속하려면

- 꼭 `APP_PASSWORD` 를 길게 정해 주세요.
- 시놀로지 **역방향 프록시**로 HTTPS 를 붙이는 걸 권장해요.

## 내 컴퓨터에서 개발하기

```bash
npm install
npm run dev
```

`http://localhost:5173` 에서 열려요. 서버(5210)도 함께 켜져요.

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 실행 (화면 자동 새로고침) |
| `npm run build` | 화면을 `dist/` 로 빌드 |
| `npm start` | 빌드된 화면과 서버를 5210 포트로 실행 |
| `npm run typecheck` | 타입 검사 |

### 환경 변수

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `5210` | 서버 포트 |
| `DATA_DIR` | `./data` (도커에서는 `/data`) | DB와 업로드 파일 위치 |
| `APP_PASSWORD` | (비어 있음) | 정하면 로그인 화면이 생겨요 |
| `MAX_UPLOAD_MB` | `20` | 올릴 수 있는 파일 크기 |


### 데이터베이스 API

데이터베이스와 항목은 모두 `pages` 표에 들어 있고 `kind` 로 구분해요 (`page`, `database`, `row`). 항목은 데이터베이스 페이지의 하위 페이지라서 휴지통·되돌리기가 그대로 적용돼요.

| 주소 | 하는 일 |
|---|---|
| `POST /api/pages` `{ kind: 'database' }` | 새 데이터베이스 |
| `GET /api/databases/:id` | 데이터베이스와 속성 정의, 항목 목록 |
| `POST /api/databases/:id/rows` | 새 항목 (`title`, `props`, `position`) |
| `PATCH /api/pages/:id` `{ schema }` | 속성 정의와 보기 설정 저장 |
| `PATCH /api/pages/:id` `{ props }` | 항목 속성 값 바꾸기 (`null` 이면 지움) |

에디터는 [BlockNote](https://www.blocknotejs.org/)를 사용해요.
