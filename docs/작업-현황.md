## 구조 메모

- **서버**: `server/index.js`(Express 5, API·로그인·업로드), `server/db.js`(페이지·DB 저장소, `node:sqlite`), `server/widgets.js`(홈 위젯 표)
- **화면**: `src/App.tsx`(주소: `/` 홈, `/p/:id` 페이지, `/w/:id` 위젯 상세), `src/components/database/*`, `src/components/home/*`
- **위젯 데이터**: 위젯마다 `config` JSON에 저장. 모양은 `src/components/home/model.ts`
- **차트 색**: `--chart` 토큰(강조색별, 라이트·다크 각각 대비 검사 통과값). 파스텔 원색은 다크 모드 막대로 쓰면 너무 흐림
- **로컬 빌드 주의**: OneDrive 폴더 안에서는 Vite가 `dist`를 비우다 비정상 종료함 → `rm -rf dist` 후 빌드

## 미비 사항 · 할 일

### 1순위: 사용자 계정과 협업 (설계만 끝남, 코드 아직 없음)

사용자와 정한 방향: **공용 + 개인 페이지**, **초대 링크로만 가입**, 자체 계정 먼저(구글 로그인은 HTTPS 도메인 생긴 뒤).

1. **계정**: `users`(아이디, scrypt 비밀번호, 별명, 프로필 사진, 색, 관리자/멤버), `sessions`(토큰 해시, 만료), `invites`(코드, 만료, 사용 여부)
   - 첫 실행 시 관리자 계정 만들기 화면. `APP_PASSWORD`는 더 이상 쓰지 않음
   - API 초안: `/api/auth/status·setup·login·logout·register`, `/api/me`(프로필·비밀번호), `/api/admin/invites`, `/api/users`
2. **권한**: `pages.private_owner` 컬럼(NULL=공용, 사용자 id=개인). 하위 페이지·DB 항목은 부모 값을 물려받음. 모든 페이지 API에서 접근 확인
   - 위젯(`widgets.user_id`)과 테마 설정(`ui:<사용자id>`)은 사람마다 따로. 기존 데이터는 첫 관리자에게 넘김
3. **실시간 동시 편집**: Yjs v13 + Hocuspocus(`@hocuspocus/server`·`@hocuspocus/provider` 4.7.x)
   - 화면: `withCollaboration()` (`@blocknote/core/yjs`)에 `fragment`, `provider`, `user{name,color}`, `showCursorLabels: 'always'` → 다른 사람 커서와 이름표 표시
   - 서버: 같은 HTTP 서버에 웹소켓 연결(`/collab`). `pages.ydoc` BLOB에 저장. 처음 열 때 기존 JSON 본문을 `@blocknote/server-util`로 Y 문서로 바꾸고, 저장할 때 다시 JSON으로 바꿔 `content`도 갱신(검색·복사·홈 위젯이 계속 동작하도록)
   - 페이지 복사 시 `ydoc`은 비워 두고 JSON에서 다시 만들기
4. **변경 알림**: `/events` 웹소켓으로 "페이지 바뀜", "DB 바뀜", "누가 어느 페이지를 보는지"를 알림. 요청마다 `X-Client-Id`를 붙여서 내가 일으킨 알림은 무시
5. **화면**: 로그인·가입(초대 링크)·프로필(별명·사진·색·비밀번호)·관리자(초대·멤버) 화면, 사이드바 '공용'/'내 페이지' 구역, 위쪽에 지금 보는 사람 프로필 사진

### 그 밖에

- **확인 필요**: 끌어서 옮기기(사이드바·칸반·캘린더·타임라인·위젯·링크 표)를 실제 마우스로 시험하지 못함. 코드로 보낸 이벤트로만 확인
- **도커 빌드**: 개발 PC에서는 도커가 꺼져 있어 직접 빌드해 보지 못함. NAS에서 빌드해서 쓰는 중
- **앱으로 설치(PWA)**: 매니페스트·아이콘 추가 필요. HTTPS 도메인이 있어야 설치 버튼이 뜸
- **내보내기/가져오기**: 전체 데이터 zip 백업·복원 버튼 없음 (지금은 `data` 폴더를 직접 복사)
- **위젯 아이디어**: 날씨, 포모도로 타이머, 기분 기록
- **알려진 한계**
  - 타임라인은 오늘 기준 앞뒤 일정 범위만 그림(주 단위 84일, 월 단위 300일). 범위 밖 항목은 화살표로 이동
  - 위젯 내용(가계부 기록 등)은 위젯 하나의 JSON에 모두 들어가서 아주 많이 쌓이면(200KB 제한) 나눠야 함
